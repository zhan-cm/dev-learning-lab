## 📖 About

`dev-learning-lab` 是我的个人软件开发学习仓库。

这里集中保存从编程基础到后端开发过程中产生的：

- 📚 学习笔记与知识整理
- 💻 示例代码与语法练习
- 🧩 数据结构与算法实践
- 🛠️ 框架与中间件实验
- 🧪 技术验证与 Demo
- 🚀 软件开发学习记录

这个仓库会随着我的学习持续更新，而不是一个已经“完成”的项目。

> Learn → Practice → Build → Review → Improve

## 🎯 Purpose

这个仓库主要用于三个目的：

**1. 建立完整的知识体系**

不仅保存“学过什么”，还希望逐渐理解不同技术之间的联系。

```text
Programming
     ↓
Data Structures
     ↓
Database / Network
     ↓
Java Backend
     ↓
Spring Ecosystem
     ↓
Middleware
     ↓
Distributed Systems
```

**2. 保留真实的学习轨迹**

仓库中的部分代码可能来自早期学习阶段，因此并不代表最佳实践。

我希望保留这些内容，因为它们也是技术成长过程的一部分。

**3. 从学习代码走向工程实践**

长期目标不是收集 Demo，而是逐渐完成：

```text
Know
  ↓
Understand
  ↓
Practice
  ↓
Build
  ↓
Engineer
```

## 🌱 Repository Philosophy

这个仓库遵循几个简单原则：

```text
Write code.
Understand why it works.
Break it.
Fix it.
Record what was learned.
Build something better next time.
```

学习不是为了堆积代码，而是为了逐步获得解决真实问题的能力。
